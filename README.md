# GIS Timeline Dashboard
 
Interactive GIS map with time-based data layers, timeline sync, and Recharts analytics.
 
> 🚧 **Work in progress.** The project is just starting. This README will be updated as the work goes on.
 
## About
 
A small React + TypeScript app with an interactive map, several data layers, a timeline and charts.
The goal is to build one data flow between the map, the timeline and the charts, so all of them always show the same state.
 
## Planned stack
 
- React
- TypeScript
- [Vedro](https://www.npmjs.com/package/vedro) for state management
- Recharts for charts
- Map library: to be decided
- MSW for mocking API

## Planned features
 
- [ ] Interactive map
- [ ] 3 data layers (for example temperature, wind, insolation) with mock data
- [ ] Turning layers on and off
- [ ] Timeline with several time points and smooth switching between them
- [ ] Chart with time-series data, synced with the timeline and the map
- [ ] Choosing a time point directly on the chart
- [ ] Loading states and handling of race conditions
- [ ] Deployed demo
